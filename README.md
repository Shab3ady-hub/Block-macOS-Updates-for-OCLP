
# Block macOS Updates for OCLP

A free, open-source app that blocks macOS updates and removes the "Update to the new macOS" banner and red notification badge. Everything is backed up first, with a one-click undo.

## ⚠️ Important

- **Blocks ALL macOS updates**, including security updates.
- Designed primarily for Macs running OpenCore Legacy Patcher (OCLP).
- Backs up system changes before modifying them.
- Deletes already-downloaded macOS updates. This cannot be undone.
- All other changes can be reversed using **Undo the Block**.
- Use at your own risk. Not signed or notarized by Apple.

## Compatibility

- **Ventura 13:** Verified (MacBook Air 2015, OCLP).
- **Sequoia 15:** Partially verified.
- **Other versions:** Not tested.
- **Apple Silicon:** Not tested.

## Features

- Block automatic macOS updates.
- Remove upgrade notifications and badges.
- Check block status and repair if needed.
- Restore previous settings with one-click undo.
- Automatic backups and debug reports.

## Usage

1. Download the `.zip` file from this repository.
2. Right-click `Block macOS Updates.app` and select **Open**.
3. Choose **Block macOS Updates**.
4. Enter your administrator password.
5. Restart your Mac.

To reverse the changes, select **Undo the Block**.
